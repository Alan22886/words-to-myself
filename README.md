# 留一页 · 给自己的话

极简黑色个人提醒工具，固定三页，支持排版、图片、待办、加密跨端同步，以及双击切换英文新闻遮挡。

在线：https://alan22886.github.io/words-to-myself/

## 使用

- 底部 01 / 02 / 03 切换三页，每页可选填标题。不增加、删除页面，也没有归档或版本列表。清空仅清空当前页，保存后生效。
- 排版工具栏提供红、蓝、白三个小色点，先选中文字再点色点改色。颜色随正文加密同步。
- 点击编辑仅展示标题和正文两个框，不自动聚焦或唤起键盘；点输入框才输入。标题右侧 × 清空标题。
- 编辑后点保存。切页会在内存保留当前草稿，页签的小点表示有草稿；关闭或刷新页面仍可能丢失未保存内容。
- 待办：粘贴多行再点“待办”，各行转换为可勾选项；也支持只转换选中的文字。回车新增一项，空白项再回车返回普通正文。阅读时勾选自动同步，不切换布局。
- 阅读模式下，双击正文或任意非按钮空白处进入英文新闻遮挡，再双击退出。编辑模式下不触发，保留双击选词。遮挡页使用虚构英文文化报道，不请求新闻服务，无图片、日期或功能按钮。
- 左上角“保存于……”表示当前页最近成功同步保存的时间，按设备本地时区显示。新页显示“尚未保存”。待办勾选保存也会更新这个时间。
- 点击左上角时间退出登录：确认后清除此设备登录、密钥和缓存，云端三页保留。再次使用原账号与密码登录即可恢复。
- 同步状态只显示小图标：圆圈对勾为已同步，旋转箭头为同步中；离线、草稿、冲突为静态符号。鼠标悬停或屏幕阅读器可读取状态说明。

## 同步规则

两端登录同一账号。保存后由 Firebase 实时订阅自动更新，无需刷新。不同页面同时保存时自动合并；同页发生冲突时不覆盖草稿，可确认“使用另一端”或“保留我的修改”。保留操作仍检查云端版本，防止覆盖选择之后的新修改。

离线可阅读已缓存内容；编辑保留在当前打开的页面，联网后再保存。旧单页内容自动出现在第一页，第二、三页为空。其他设备也应更新至三页版本，再进行修改。

## 图片与容量

原图限 15 MB，加入时自动缩至最长边 1400 像素，转为 JPEG。标题最多 100 个 UTF-16 单位。正文没有单独字数限制；三页的文字、排版和图片编码合计最多 **10 MiB（10,485,760 字节，按加密前的 UTF-8 JSON 计）**。图片编码和加密会产生额外开销，不等于可上传 10 MiB 原图。

大内容使用最多 14 个、每个不超过 1,000,000 字符的密文分块。单次 SDK 写入保持在 16 MB 限制内，小内容继续兼容原密文格式。本地密文保存在 IndexedDB，避免 localStorage 的小容量限制；localStorage 仅保留连接信息和解密密钥。超过额度会阻止提交，保留编辑框。

## Firebase

配置在 `config.js`，是可公开的 Web 配置，不含密码、管理密钥或私钥。使用 Email/Password 登录，账号由项目所有者在控制台创建。`database.rules.json` 只允许已登录账号访问自己的 `pages/<uid>/current`。扩容需要发布新版规则；当前规则已在控制台成功发布。

内容使用 AES-256-GCM 加密，每次随机 IV。PBKDF2-SHA256（600000 次）结合账号 UID 和密码派生密钥。密码不保存；浏览器保留登录与解密密钥，所以能访问此浏览器存储的人可能解密。**不要直接重置密码**，新密码无法解密旧内容；本版不提供密钥迁移或密码找回。

保持 Firebase Spark 免费方案，不需要自行运行服务器。当前官方额度为 1 GB 数据库存储、10 GB/月下载、100 个同时连接。Spark 超限限制服务而非按超量扣费；不要为此工具升级 Blaze 或绑定 Cloud Billing。图片越多，同步下载量越大。

## 安装与更新

iPhone Safari 分享 → 添加到主屏幕；Android 浏览器菜单 → 安装应用。主屏幕入口可能使用独立存储，需登录一次。已有缓存的设备可离线阅读；首次登录及同步需能访问 GitHub Pages 和 Firebase。

页面禁用双击缩放、横向拖动和顶部回弹，保留正常竖向滚动。iOS 系统手势仍需实机验收。

右上角显示测试版本：线上为 `beta.<Actions 运行编号>.<重试编号>`，本地构建为 `beta.<源码摘要>`。打开或从后台返回检查更新，新版完整缓存后再切换。编辑、有草稿或正在遮挡时延后刷新。

```sh
npm ci

python3 -m http.server 4181 --bind 127.0.0.1

```

Node.js 24。`npm run build` 生成 `dist/`，推送 main 触发 GitHub Pages。测试使用模拟 Firebase，不读取或修改真实账号数据，覆盖：登录、旧单页迁移、五行粘贴、选中转换、回车退出、长列表勾选滚动稳定、实时同步、同页冲突、跨页并发合并、草稿切页、退出重登、遮挡手势、大内容分块及缓存、10 MiB 上限。真实网络和 iOS 主屏幕模式需实机检查。
